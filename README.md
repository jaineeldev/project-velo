# project-velo

A client workflow platform for freelance developers and dev agencies.

> ⚠️ Early development — name and branding TBD

## What We're Building

A PWA that removes the business admin headache for freelance devs and agencies of any size. You send a proposal to a client, they approve it, and the project, milestones, and invoice are automatically created. No copy-pasting, no jumping between tools.

Clients get a shareable link to track progress and leave feedback. No login, no download needed.

## The Problem

Right now devs are stitching together Notion, Google Docs and Xero just to run their client work. None of it talks to each other. We're replacing all of that with one place.

## Stack

- Next.js 14 + TypeScript
- Tailwind CSS + Framer Motion
- Neon (PostgreSQL)
- Clerk (Auth)
- React-PDF
- Vercel
- next-pwa
