# project-velo

A client workflow platform for freelance developers and dev agencies.

> Brand name TBD. Private build — not open for external contributions.

## What it does

Removes the business admin headache for freelance devs and agencies. Send a proposal, client approves it, and everything else is created automatically — project, milestones, invoice. No copy-pasting, no jumping between tools.

## Stack

- Next.js 14 + TypeScript + Tailwind CSS
- Neon (PostgreSQL)
- Clerk
- Vercel
